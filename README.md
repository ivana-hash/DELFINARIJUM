# Delfinarijum

Moj prvi sajt, fakultetska vežba iz 2025. godine. Delfinarijum je izmišljen park. Fotografije su preuzete sa interneta i koriste se samo u edukativne svrhe.

Sajt uživo: https://ivana-hash.github.io/DELFINARIJUM/

## Stranice

- Početna (vesti, o parku, lokacija, zanimljivosti, kontakt)
- Kalendar aktivnosti
- Kupovina karata (forma sa validacijom)
- Galerija
- Animacija (CSS animacije)

## Tehnologije

HTML, CSS, JavaScript, bez biblioteka.
